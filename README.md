# 단기납종신보험 계리 계산기

통계청 2024년 완전생명표를 사용해 **단기납종신보험(5·7·10년납 종신보험)**의 순보험료, 영업보험료, 책임준비금, 해지환급금(근사), 환급률을 계산하는 Streamlit 웹앱입니다.
계리 직무 포트폴리오용으로 만들었으며, 계산 과정을 공식과 실제 대입 숫자로 함께 보여 주는 **학습 모드**를 포함합니다.

> ⚠️ 학습·포트폴리오용 계산기이며 실제 상품의 보험료와 다를 수 있습니다. 사업비 기본값은 예시이며 실제 상품 값이 아닙니다.

### 학습 모드

모든 그래프 옆에 해당 공식과 현재 조건으로 대입한 숫자를 함께 보여 줍니다.

1. **생명표 → 생존곡선**: 나이별 사망확률 qx(로그 축)와 생존자 수 lx를 남녀 비교로 표시
2. **수지상등 원칙**: 보험료 수입 현가(P·ä)와 보험금 지출 현가(S·A)가 같아지는 막대. 사업비를 켜면 영업보험료 현가가 순보험료 현가 + 사업비 현가로 쌓이는 누적 막대로 바뀜
3. **준비금이 쌓이는 원리**: 경과연도 k를 고르면 (k−1)V → +보험료 → +이자 → −사망보험금 기대지급 → +생존자 분배 → kV 로 이어지는 폭포형 차트와 재귀식
4. **슬라이더로 공식 체험**: 예정이율·가입연령을 움직이면 A_x, ä_x, ä_{x:m}, P와 대입 숫자가 실시간으로 바뀜
5. **가정 변경 시나리오**: 사망률 배수(남/여, 적용 연령 구간), 예정이율, 사업비를 바꿔 기준 가정과 비교. 예시 버튼 "남성 사망률 전 연령 2배", "예정이율 −1%p", "사업비 0"

- 검증: 남자 q₀ = 0.00261, 여자 q₀ = 0.00214, l₀ = 100,000일 때 남자 l₁ = 99,739, 여자 l₁ = 99,786 (PDF 원문과 일치)

## 계리 가정과 공식

연 1회 연초 납입, 사망보험금은 사망 연도 말 지급(이산 모형). 예정이율 $i$, $v = 1/(1+i)$, $d = i/(1+i)$.
가입금액 $S$, 가입연령 $x$, 납입기간 $m$.

### 기수표

$$D_x = v^x l_x,\quad N_x = \sum_{t \ge x} D_t,\quad C_x = v^{x+1} d_x,\quad M_x = \sum_{t \ge x} C_t$$

$$A_x = \frac{M_x}{D_x},\quad \ddot{a}_{x:\overline{m}|} = \frac{N_x - N_{x+m}}{D_x},\quad \ddot{a}_x = \frac{N_x}{D_x}$$

### 보험료

순보험료(연납):

$$P = \frac{S \cdot A_x}{\ddot{a}_{x:\overline{m}|}}$$

영업보험료(연납, 수지상등). α 신계약비(가입금액 대비, 1회), β 납입 중 유지비, β' 납입 후 유지비(가입금액 대비, 매년), γ 수금비(영업보험료 대비, 납입 중):

$$G = \frac{S A_x + \alpha S + \beta S\, \ddot{a}_{x:\overline{m}|} + \beta' S\,(\ddot{a}_x - \ddot{a}_{x:\overline{m}|})}{(1-\gamma)\, \ddot{a}_{x:\overline{m}|}}$$

월납 환산(Woolhouse 2항 근사):

$$\ddot{a}^{(12)}_{x:\overline{m}|} \approx \ddot{a}_{x:\overline{m}|} - \frac{11}{24}\left(1 - {}_mE_x\right),\quad {}_mE_x = \frac{D_{x+m}}{D_x},\quad \text{월납} = \frac{\text{연납} \times \ddot{a}_{x:\overline{m}|} / \ddot{a}^{(12)}_{x:\overline{m}|}}{12}$$

### 책임준비금 (순보험료식, 장래법, 경과 k년 말)

$${}_kV = \begin{cases} S\,A_{x+k} - P\,\ddot{a}_{x+k:\overline{m-k}|} & (k < m) \\ S\,A_{x+k} & (k \ge m) \end{cases}$$

재귀식(학습 모드 ③), 납입 후에는 $P = 0$:

$$\left({}_{k-1}V + P\right)(1+i) = q_{x+k-1}\,S + p_{x+k-1}\,{}_kV$$

### 해지환급금(근사)과 환급률

$$\text{미상각 신계약비}_k = \alpha S \cdot \max\left(0,\ 1 - \frac{k}{\min(m, 7)}\right),\qquad CV_k = \max\left(0,\ {}_kV - \text{미상각 신계약비}_k\right)$$

$$\text{환급률}_k = \frac{CV_k}{G \cdot \min(k, m)} \times 100\%$$

## 근사의 한계 (실제 상품과 다른 점)

- **해지환급금은 단순 근사입니다.** 순보험료식 준비금에서 신계약비 α·S를 min(납입기간, 7년)에 걸쳐 정액 상각한 미상각분만 뺍니다. 실제 표준해약공제 규정, 저해지·무해지 구조, 납입 후 환급률 가산 등은 반영하지 않습니다.
- **그래서 10년 시점 환급률이 시판 상품보다 낮게 나옵니다.** 시판 단기납종신은 납입 중 해지환급금을 낮추는 대신(저해지) 납입 완료 후, 특히 10년 시점의 환급률을 높게 설계합니다. 이 모델은 그런 구조 없이 일반 종신보험의 준비금을 그대로 쓰므로 위 예시처럼 10년 환급률이 약 89~99%에 머무는 것이 정상입니다.
- **월납 보험료는 근사치입니다.** 연납 보험료를 Woolhouse 2항 근사로 환산했고, 월납 사업비 구조는 따로 반영하지 않습니다.
- **사업비 기본값은 예시입니다.** 실제 상품의 사업비 수준이 아니며 사이드바에서 바꿀 수 있습니다.
- **기타 단순화**: 사망보험금은 사망 연도 말 지급(이산 모형), 위험률은 국민생명표(경험생명표 아님) 그대로 사용, 준비금은 순보험료식(영업보험료식·Zillmer식 아님), 해지율·선택효과 미반영.

## 실행 방법

Python 3.11에서 확인했습니다. 패키지 버전은 `requirements.txt`에 고정되어 있습니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 열립니다.

테스트(100개):

```bash
python -m pytest -q
```

테스트 항목: 생명표 검증값, 항등식 $A_x = 1 - d\,\ddot{a}_x$(허용오차 1e-10), 수지상등, ${}_0V = 0$·준비금 비음수·단조 증가, 사업비 0이면 G = P·사업비 양수면 G > P, 준비금 재귀식, 사망률 배수 1.0이면 기준과 일치·배수 > 1이면 P 증가, $CV_k \le {}_kV$·상각 완료 후 $CV_k = {}_kV$ 등.
